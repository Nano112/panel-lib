panel-lib 0.1.4

The bundled Inter and Font Awesome fonts now include their license notices in
every jar. Release verification checks that the notices are present.

This includes the quieter toolbar and editor ownership fixes from 0.1.3: menus
start with the contributing mods, layout controls use a small window icon, and
the overlay yields input and restores the viewport around Axiom.

All six Minecraft targets build and pass the panel tests and packaging checks.
Connector bundles the library, so its users need no separate installation.

AI assistance was used for code and release text.

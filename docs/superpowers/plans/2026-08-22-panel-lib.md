# panel-lib Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Standalone Fabric library mod providing one shared Dear ImGui overlay (toolbar + dockspace + theme + widgets) that any mod can contribute panels/menus/keybinds to via a `panellib` entrypoint.

**Architecture:** Port SchematioConnector's proven ImGui framework (manager, custom GL3 renderer, overlay, dock host, input + present mixins) into `dev.harrison.panellib`, replace the app-specific toolbar with a registry-driven one, replace the brand theme with a `Theme` token object + new default, and expose a small API. MC-Inspector becomes the first consumer.

**Tech Stack:** Kotlin 2.4.0, Fabric Loom 1.16-SNAPSHOT, Stonecutter 0.9.5, imgui-java 1.89.0, JUnit 5.

**Spec:** `docs/superpowers/specs/2026-08-22-panel-lib-design.md`

## Global Constraints
- Versions 1.21.8–1.21.11, 26.1, 26.2; active 1.21.11; sources are written in 1.21.11 form with `//? if` splits (uncommented branch = active version).
- Mod id `panellib`; package `dev.harrison.panellib`; imgui.ini `panellib-imgui.ini`.
- No schemat.io references; all colours via `Theme` tokens (no literals in widgets/toolbar — test-enforced).
- Commit after every task.

### Task 1: Scaffold + imgui deps + fonts + empty client init (builds, runs, logs)
- Copy the MC-Inspector gradle scaffold (settings/build/gradle.properties/fabric build + stonecutter + versions); rename to `panel-lib` / `panellib`; add imgui-java deps with `include` + `exclude(group="org.lwjgl")` and `testRuntimeClasspath` exclusions (from Schematio); add `maven-publish` with artifactId `panel-lib-mc$mcVersion`.
- Copy the three ttf files to `assets/panellib/fonts/`.
- `PanelLibClient : ClientModInitializer` logs init. Build `:fabric:1.21.11:build`. Commit.

### Task 2: Theme + fonts + icons + widgets (pure Kotlin where possible; tests)
- `theme/Theme.kt` (data class of ImVec4 tokens + metrics, `fromArgb` helpers), `theme/Themes.kt` (DEFAULT "Graphite"), `theme/ThemeApplier.kt` (`apply(theme)`/`unapply()`; `colorMap(theme)` maps EVERY `ImGuiCol` slot), `theme/Fonts.kt`, `theme/Icons.kt` (+ `extra` registration), `widgets/{Anim,Widgets,ConfirmModal}.kt` taking colours from `Theme.current`.
- Tests: `ThemeApplierTest` (reflection over `ImGuiCol` public static int fields — all mapped, count matches), `IconsTest` (glyph ranges sorted/zero-terminated, extras included), `AnimTest`, `ThemeTest` (argb parse, copy override).
- Commit.

### Task 3: Framework port — manager, renderer, overlay, dock host, panel manager, registry-driven toolbar
- Port `ImGuiManager`, `ImGuiGl3Renderer` verbatim (package + ini name changed).
- `framework/PanelManager` (open/close/toggle/closeTop/renderAll with begin/end wrapper per `PanelSpec`), `core/Registry` (mods → panels, menu items), `framework/Toolbar` (wordmark + per-mod menus + Layout menu), `framework/DockHost` (default layout docks the FIRST registered panel right), `framework/Overlay` (toggle/ensureOpen/onEscape/isFocused/render).
- Tests: `PanelManagerTest`, `RegistryTest` (unique ids `<mod>:<id>`, order preserved, duplicate id throws).
- Commit.

### Task 4: Mixins (input + present) + keybinds + API + entrypoint wiring
- Port `KeyboardMixin`, `MouseMixin`, `RenderSystemMixin`, `GlSurfaceMixin` (names → `panellib$…`, `Overlay`).
- `core/Keybinds` (overlay toggle K + API-registered binds; `KeyMappingHelper` on 26.x split), `core/PanelLibConfig` (`accent` override), `core/PanelLibApiImpl`, `PanelLib.api()`, `PanelLibClient` loads entrypoints `FabricLoader.getEntrypoints("panellib", PanelLibEntrypoint::class.java)` after registry creation, `CLIENT_STOPPING → ImGuiManager.shutdown()`, END_CLIENT_TICK → `Keybinds.handleInput()`.
- `lang/en_us.json` keybind labels. Build all versions; `publishToMavenLocal` for 1.21.11. Commit.

### Task 5: Dogfood via MC-Inspector
- MC-Inspector: `modImplementation("dev.harrison:panel-lib-mc$mcVersion:0.1.0")` + `include`, mavenLocal repo; `"panellib"` entrypoint `InspectorPanels` registering mod "Inspector" with an **MCP Status** panel (port, tool calls, last tool, uptime, a "Copy URL" secondary button, a `Widgets.badge`) and keybind `I` → toggle panel.
- Run client; via MCP: `press_key k` → screenshot shows toolbar; `press_key i` → status panel docked right; click the panel's button via `mouse_click` using image coords → log line; Escape closes panel then overlay. Fix whatever is wrong. Commit both repos.
